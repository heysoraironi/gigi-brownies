# GIGI FM music folder

Drop songs in this folder (mp3, ogg, wav, m4a, aac, flac) and they show up on the
GIGI FM radio automatically, after the built-in chiptunes. No other setup needed.

Only add music you have the rights to share. Everything in this repo is public.

Songs play in alphabetical order, so you can prefix names like `01-`, `02-` to set the order.
